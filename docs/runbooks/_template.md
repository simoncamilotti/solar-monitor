# Titre de l'opération

**Quand** : la situation qui déclenche l'opération.
**Durée** : ordre de grandeur. **Risque** : faible | moyen | élevé.

## Prérequis

- Accès, outils, informations à réunir avant de commencer.

## Procédure

1. Étape, avec la commande exacte :

   ```sh
   commande
   ```

2. Vérification attendue après l'étape.

## Vérifier

Comment s'assurer que l'opération a réussi.
